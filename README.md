# 💳 Expense Tracker PRO

A sleek, responsive, full-stack Personal Expense Tracker built with **Python (Flask)**, **SQLite**, and vanilla **HTML/CSS/JavaScript**. Features a modern **Glassmorphism UI**, **Indian Rupee (INR - ₹)** formatting, **Multi-User Authentication**, **Monthly Budget Monitoring**, and interactive **Chart.js** analytics.

---

## ✨ Features

- **🔐 Multi-User Support & Authentication:** Secure registration and login with password hashing (`werkzeug.security`). Each user's expense data is isolated.
- **🎨 Glassmorphism UI:** Ultra-modern dark theme with animated glowing background orbs, frosted glass containers, and responsive card layouts.
- **🎯 Monthly Budget & Visual Alerts:** Set a monthly spending cap with a real-time progress bar. Includes warning alerts at 80% and 100% threshold limits.
- **📊 Spending Analytics:** Visual category breakdowns using Chart.js doughnut graphs.
- **🇮🇳 Indian Rupee (INR) Support:** Formatted numbers displaying `₹` currency symbols throughout the UI.
- **📑 Data Management:** Add, view, delete individual records, or clear all expense history in one click.

---

## 🛠️ Tech Stack

- **Backend:** Python 3, Flask, SQLite3
- **Frontend:** HTML5, CSS3 (Glassmorphism), JavaScript (ES6+, Chart.js)
- **Deployment:** Render / PythonAnywhere / Koyeb / Vercel (Gunicorn WSGI)
